# Fairness audit

An independent audit of the code and the harness of this repository (programs, `scripts/`, `awfy/`),
made 2026-11-20 on `dev` at 3c21092, before the first timing on sysl 0.12.0. It audits whether the
numbers can be trusted, not what they say. Each finding has a severity:

- **headline**: would change a headline claim (a geometric mean, or who is fastest on a program);
- **ratio**: would change one ratio by more than 5%;
- **disclosure**: changes no number materially, but a reader must be told.

Every headline and ratio finding is fixed on this branch; every disclosure is in README.md
("Known weaknesses of the plain columns", "Methodology, and what a reader should know") or in
`awfy/README.md`. No timing was taken: an urgent sysl 0.12.0 gate was running when the audit
started, and a merge train held marshal's queue when the fixes were done, so the size of A1 and A2
is unmeasured. Every changed program was rebuilt and verified through marshal (jobs 8057, 8074).

## Checked and found sound

- **Thread count**: no program starts a thread. No build passes `-fopenmp`, so the C and Fortran
  OpenMP directives are inert; Rust, C++ and Swift programs were made sequential (SOURCES.md).
- **The sysl programs do the work.** Each sysl program was read against the C program: binary-trees
  allocates every node, leaves included (peak 50 MiB at 48 bytes a node, as FINDINGS §4 says),
  k-nucleotide builds a full table for every k, mandelbrot iterates to 50 with C's escape test,
  spectral-norm runs ten rounds of `A^T A`. `sysl-idiomatic` keeps every bounds check.
- **Floating point in the main suite**: sysl fuses exactly as clang's default `-ffp-contract=on`
  (`fp_contract.sysl`); no sysl program uses reassociation. The C and sysl arithmetic is the same.
- **Inputs**: every language reads the same generated file at each size, through hyperfine's
  `--input`, after the same three warm-ups; no build or I/O set-up is inside any timing.
- **The output checks can fail**: the small sizes compare with the Game's own files byte for byte
  and the timed sizes with a hash, and outputs depend on the work done (no program's output is
  computable without it, binary-trees' counts aside, whose sysl programs were read).
