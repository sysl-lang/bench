## Flags

- **sysl**: `sysl build --release -O3 --cpu native`
- **c**: `clang -std=gnu17 -O3 -march=native`
- **cpp**: `clang++ -std=c++20 -O3 -march=native`
- **rust**: `rustc --edition 2021 -C opt-level=3 -C target-cpu=native`
- **swift**: `swiftc -O`
- **zig**: `zig build-exe -O ReleaseFast -mcpu=native -fsingle-threaded`
- **nim**: `nim c -d:danger --opt:speed --mm:orc --cc:clang --passC:-march=native --threads:off`
- **go**: `go build (default flags: Go has no optimisation level; bounds checks stay on)`
- **d**: `ldc2 -O3 -release -mcpu=native (-release drops asserts and the bounds checks of @system code)`
- **odin**: `odin build -o:speed -microarch:native (bounds checks stay on)`
- **c3**: `c3c compile -O3 (-O3 is c3c's unsafe mode: runtime bounds checks and contracts are off; c3c has no native-CPU option for arm64)`
- **ada**: `gnatmake -O3 -gnatp -march=native (-gnatp suppresses every run-time check, bounds checks included, as C's -O3 has none; GNAT is GCC's Ada front end and uses GCC's back end)`
- **java**: `javac, then java -cp (default JIT flags; bounds checks stay on; JVM startup and JIT warm-up are inside every timed run, as on the Benchmarks Game)`
- **eiffel**: `ec -finalize -c_compile, ECF target `release`: every assertion off (precondition, postcondition, check, invariant, loop); the C compiler is the machine's clang with EiffelStudio's own flags, which have no native-CPU option; array indices are not range-checked, as they are by a precondition`
- **eiffel-contracts**: `the same source as `eiffel`, ECF target `contracts`: precondition, postcondition, check, invariant and loop (invariant and variant) assertions all on`
- **julia**: `julia -O3 --check-bounds=no --startup-file=no (JIT: every timed run includes Julia's startup and compilation, as on the Benchmarks Game)`
